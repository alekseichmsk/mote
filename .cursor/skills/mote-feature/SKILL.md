---
name: mote-feature
description: Используй при реализации новой фичи или задачи из ROADMAP.md / tasks/.
---
1. Найди задачу в ROADMAP.md и tasks/. Прочитай связанные модули целиком.
2. Проверь API нужных библиотек через context7.
3. Напиши design-doc в vault/design/<фича>.md: цель, затронутые файлы, поток данных,
   события mote://, команды invoke, логи [mote], риски. Покажи и жди «ок».
4. Реализуй минимальными шагами, после каждого — сборка.
5. cargo fmt, cargo clippy -D warnings, npx tsc --noEmit.
6. Вызови субагента reviewer, исправь найденное.
7. Вызови субагента qa — получи чеклист ручного теста.
8. Отчёт: файлы, чеклист, ожидаемые логи, что не проверено. Отметь задачу в tasks/.
   Обнови vault/ по скиллу docs-obsidian.
