name: mote-smoke-test
description: Используй перед тем как считать фичу готовой или баг исправленным.
---
1. Составь чеклист: шаг → ожидаемое поведение → ожидаемые строки логов [mote].
2. Приложения для текстовых фич: Notepad (Win11), Cursor, Chrome, Word.
3. Обязательная регрессия: погода, Википедия `?`, музыка, факты, анимация очков, spellcheck, числа → текст.
4. Для LLM/голоса: с моделью и без, игровой режим (запустить полноэкранное приложение → VRAM освобождена).
5. Дополнительно: `npm test`, `npm run qa` когда менялись curious/API.
6. Попроси пользователя пройти чеклист и прислать логи. Без этого не писать «готово».
