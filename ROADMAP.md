# Mote — Roadmap и архитектура

Канон в корне репо. Черновик/зеркало: `vault/mote-roadmap.md`. Настройка Cursor: `vault/mote-cursor-setup.md`. Задачи: `tasks/`.

Десктоп-питомец для Windows. **Tauri 2 + Rust (`src-tauri`) + React/TS (`src`)**.
Pet-проект, сроков нет, приоритет — скорость. Разработка через Cursor с агентами.

**Принципы**
- Всё работает **оффлайн** на ПК. Сеть — только: погода, Википедия (онлайн), загрузка моделей, облачный LLM по ключу.
- Ничего не устанавливать отдельно: всё внутри установщика Mote, тяжёлые модели докачиваются из приложения.
- Не мешать играм: тяжёлые модели выгружаются из VRAM.
- Каждый ключевой шаг пишет лог с префиксом `[mote]`.

Референс-железо: RTX 12 ГБ VRAM, 32 ГБ DDR5, i5-14400. Fallback: CPU / модель меньше / только словарь.

## Общая архитектура

```
┌──────────── React UI (webview) ─────────────┐
│ Питомец (Rive) · Plaque · Настройки · Редактор│
└───────────────▲──────────────┬──────────────┘
         events │ mote://*     │ invoke
┌───────────────┴──────────────▼──────────────┐
│                Rust core                    │
│ watcher · field_text · spellcheck · digits  │
│ llm · voice · notes · reminders · clipboard │
│ pomodoro · ocr · screenshot · game_mode     │
│ storage (SQLite) · settings · secrets       │
└──────┬─────────────┬──────────────┬─────────┘
       │ sidecar     │ ONNX          │ WinRT/Win32
  llama-server   sherpa-onnx     UIA, OCR, clipboard,
  (LLM, GPU)     (голос)         toast, hotkeys
```

- **Хранилище:** `%APPDATA%\Mote\` — `mote.db` (SQLite через `rusqlite`), `models\`, `voices\`, `settings.json`.
- **Секреты:** API-ключи — Windows Credential Manager (крейт `keyring`).
- **События** Rust → UI: `mote://spell-offer`, `mote://llm-chunk`, `mote://voice-state`, `mote://reminder`, `mote://pomodoro`, `mote://pet-emotion`.
- **Глобальные хоткеи:** `tauri-plugin-global-shortcut`.
- **Состояние питомца:** один центральный `PetState` (idle / typing / thinking / listening / speaking / focus / break / sleep / happy / surprised), из которого Rive берёт анимацию.

## Фаза 1 — Стабилизация двух главных функций

### 1.1 Spellcheck в чужих окнах
**Как работает:** `watcher` замечает печать → окно наблюдения ~2.5 с → `field_text` через UI Automation → **live-spell только по delta** после `spell_baseline` (не весь документ) → `spellcheck` (Windows ISpellChecker ru-RU, fallback Hunspell) → plaque «Заменить / Скопировать» → запись по HWND. **On-demand:** выделение → `Ctrl+Shift+S` или ПКМ → «Проверить орфографию». Грамматика/запятые/смысл — фаза 2 LLM «Улучшить текст». Underline overlay — отдельная задача (UIA ranges; не canvas Paint/PS).

**Задачи**

- [ ] Поддержка Win11 Notepad (`RichEditD2DPT`: Document без ValuePattern → TextPattern только у focused-элемента) и Electron/Chromium (Cursor, браузеры).

## Фаза 2 — Встроенная нейросеть

**Как работает**
- `llama-server.exe` (llama.cpp, сборки CUDA + Vulkan) поставляется внутри установщика как Tauri sidecar (`externalBin`). Mote запускает его на `127.0.0.1:<свободный порт>` только когда нужен LLM.
- Модель скачивается с Hugging Face при первом включении: прогресс на plaque, докачка, проверка SHA256 → `%APPDATA%\Mote\models`.
  - По умолчанию **Qwen2.5-7B-Instruct Q4_K_M** (~4.7 ГБ VRAM).
  - Лёгкая: **Qwen2.5-3B-Instruct Q4_K_M** (~2 ГБ).
- `llm.rs` — один OpenAI-совместимый клиент (`/v1/chat/completions`, стриминг через `mote://llm-chunk`). Движок выбирается в настройках:
  1. **Встроенная** (sidecar)
  2. **Ollama** (`http://localhost:11434/v1`)
  3. **Облако** по API-ключу (OpenAI / OpenRouter / Groq / любой OpenAI-совместимый)
- **Игровой режим (`game_mode.rs`):** раз в несколько секунд проверяется окно на переднем плане. Полноэкранное приложение или процесс из списка игр → sidecar останавливается (VRAM = 0), Mote работает на словаре. После выхода из игры модель снова грузится по первому запросу. Дополнительно: выгрузка после N минут простоя и режим «только CPU».

**Где используется**
- [x] **«Улучшить текст»** (срез) — кнопка на plaque + selection; sidecar `llama-server` + GGUF в `%APPDATA%\Mote\models`; словарь мгновенный; LLM по кнопке, temperature 0. Авто на паузе / чат / game_mode — позже.
- [ ] **Переписать выделенное** (хоткей): исправить / вежливее / короче / перевести.
- [ ] **`? вопрос`** — Википедия ищет → модель отвечает по найденной статье, со ссылкой. Нет LLM → как сейчас, превью.
- [ ] **Голосовые запросы**, которые не распознал простой парсер (Фаза 3).

**Готово, когда:** модель скачивается из приложения, первый токен < 2 с на GPU, при запуске игры VRAM освобождается.

## Фаза 3 — Голос

**Как работает (всё через `sherpa-onnx`, ONNX, оффлайн)**
```
микрофон → VAD → wake word «Мод» → запись фразы
   → определение диктора (эмбеддинг → ближайший профиль)
   → речь в текст (Whisper small / Zipformer ru)
   → разбор команды (ключевые слова → иначе LLM)
   → действие + ответ голосом (Piper / Silero ru)
```
- **Wake word «Мод»** — keyword spotting, постоянно, нагрузка минимальная.
- **Профили пользователей:** Настройки → «Добавить пользователя» → имя → прочитать 3–5 фраз с экрана → сохраняется голосовой слепок (эмбеддинг) в `voices\`. Пользователей сколько угодно. По профилю: приветствие «Здравствуй, Артём», свои заметки и напоминания. Незнакомый голос → «гость».
- **Команды:** погода · музыка (пауза / дальше / назад / громче / тише) · «запиши заметку…» · «напомни через…» · «запусти помодоро» · «сколько будет…» · любой вопрос (Wiki / LLM).
- **UI:** питомец «слушает» (своя анимация), кнопка «микрофон выкл», индикатор записи.
- **Важно:** узнавание по голосу — для удобства, не защита. Ничего важного к нему не привязывать.

## Фаза 4 — Редактор скриншотов (плагин)

**Как работает:** хоткей → затемнение экрана, выбор области (или открыть / вставить картинку) → отдельное окно-редактор на canvas (Konva) → сохранить PNG / копировать в буфер.

**Инструменты**
- [ ] Стрелки, прямоугольники, текст, цвет и толщина.
- [ ] **Размерные линии** с подписью в мм или см (переключатель).
- [ ] **Масштаб по эталону:** провести линию по известному размеру → ввести «600 мм» → дальше все размерные линии подписываются автоматически в реальных единицах.
- [ ] Undo / redo, перемещение и удаление объектов.
- [ ] Включается как плагин в настройках.

Захват экрана: крейт `xcap` или `windows-capture`.

## Фаза 5 — Продуктивность

- [ ] **Заметки** — текстом или голосом, поиск, привязка к профилю, SQLite.
- [ ] **Напоминания** — «напомни через 20 минут…», «завтра в 9…». Планировщик в Rust, срабатывание — реплика питомца + toast Windows. Переживают перезапуск (хранятся в БД).
- [ ] **История буфера обмена** — последние N записей, поиск, закреп, очистка. Не сохранять из менеджеров паролей и данные с флагом `ExcludeClipboardContentFromMonitorProcessing`.
- [ ] **Калькулятор** — `+ − × ÷` в поле ввода питомца (например `= 125*4`), без скобок.
- [ ] **OCR** — хоткей → выделить область → текст в буфер. Встроенный `Windows.Media.Ocr` (русский, оффлайн).
- [ ] **Помодоро**
  - 25 мин фокус → 5 мин перерыв; после 4 циклов длинный перерыв 15–30 мин. Длительности настраиваются.
  - Запуск кликом, голосом или хоткеем. Таймер-кольцо возле питомца.
  - В фокусе питомец «работает», plaque не появляются (режим «не беспокоить»). В перерыве — анимация отдыха и «разомнись».
  - Счётчик помидорок за день, статистика за неделю.
- [ ] **Оффлайн Википедия (опция)** — Kiwix ZIM на русском: мини (~1 ГБ, начала статей) или без картинок (несколько ГБ). Отдельная загрузка, по умолчанию остаётся онлайн-поиск.
