# Improve: словарь + fallback когда 3B врёт

## Симптом
1. «Улучшить» без видимых правок (в LLM уходил уже `replaced`).
2. `пРевеТ` → модель вернула `Перевет` (7 букв), словарь правильно давал `привет`.

## Причина
- UI слал `replaced` (после словаря).
- Qwen2.5-3B иногда «исправляет» в ещё худший вариант.

## Фикс
- `SpellOfferPayload.original` → в LLM сырой текст.
- После ответа: если модель всё ещё с опечаткой (или echo) → `prefer_dict_if_model_worse` берёт `offer.replaced`.

## Как проверить
1. `пРевеТ` → Улучшить → plaque `привет`, лог `improve fallback dict`.
2. Нормальное предложение без опечаток → модель сохраняется без fallback.
