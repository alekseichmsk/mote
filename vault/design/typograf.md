# Design: Typograf на plaque

## Цель
Оффлайн типографика русского текста (кавычки «», тире —, неразрывные пробелы, `...` → `…`) по кнопке на spell-plaque. Без сети, без LLM.

## Что это не делает
Не spellcheck и не «Улучшить». Не чинит опечатки вроде «пРевеТ». Только типографские правила.

## UX (рекомендую вариант A)
Кнопка **«Типограф»** на external spell plaque рядом с «Улучшить».

1. Пользователь: live-ошибка или `Ctrl+Shift+S` по выделению → plaque.
2. Жмёт «Типограф».
3. Берём исходник: `original` → иначе `replaced` → иначе `suggestion` (как у Improve).
4. `typograf.execute(text)` в UI (webview), locale `ru` (+ `en-US` для смешанного).
5. Результат ≠ исходник → сразу `spell_replace` (как Improve). Если запись в поле не вышла — показать на plaque «готово — нажми Заменить».
6. Результат = исходник → статус «уже ок».

**Вариант B (не в этом срезе):** всегда прогонять Typograf после Заменить/Улучшить без кнопки.

## Реализация
- npm `typograf` в `src` (нулевые зависимости, оффлайн).
- Тонкая обёртка `src/lib/typograf.ts`: один инстанс, явно `htmlEntity: { type: 'default' }` (UTF-8, не `&nbsp;`).
- Отключить правила, опасные для plain text / кода (если всплывут на smoke — точечно `disableRule`).
- Иконка на plaque + `onTypografExternalSpell`.
- Лог в консоль: `[mote] typograf ok chars=N` / `noop` / `err`.

## Invoke / события
Новых Rust-команд нет. Пишем через существующий `spell_replace`.

## Риски
- Неразрывные пробелы (U+00A0) в Notepad/Chrome/Word — обычно ок; проверить вручную.
- На одном слове («привевт») пользы мало — кнопка всё равно доступна; смысл на фразах/выделении.
- Typograf может трогать дефисы в идентификаторах (`snake-case`) — на длинном выделении с кодом риск; лимит длины как у Improve (2000) и smoke на обычном тексте.

## Вне среза
Тумблер в Настройках; авто после Improve; Typograf в live-delta без кнопки.
