# Vision

**Mote** — Windows desktop companion: всегда поверх окон, помогает во всём, выглядит как живой питомец (референс — desktop companion / Grok-bot vibe), а не как панель мониторинга.

## MVP

- Прозрачный always-on-top overlay (Tauri 2)
- Аватар + bubble + чат
- Tray + `Ctrl+Shift+M`
- Локальный mock-чат без DeepSeek
- Cursor-агенты для документации, багфиксов и security

## Non-goals (сейчас)

- Управление чужим ПК / cloud desktop harness
- Полноценные runtime-агенты внутри питомца
- Реальные вызовы DeepSeek API
